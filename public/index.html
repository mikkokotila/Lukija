    A place for close reading.

    Some texts ask us to slow down. To stay with a passage, follow a note, and return with a little more understanding.

    This is a reading room for your translation as it takes shape. Open a manuscript; its words, original passages, and annotations will find their place here.

        View on GitHub

        An offline reading copy embeds this manuscript inside a new HTML file. It does not include linked images, other volumes, or your reading history. Keep private manuscripts private when sharing the copy.

        Colophon

        A reader, not a facsimile.

        Paper, ink, a fine rule, and a vermilion reading mark. The page borrows the restraint of a printed book without imitating a historical edition or adding symbols to the source.

        Chinese and English remain in the order you wrote them. Heading levels, emphasis, quotations, tables, and notes are rendered from the Markdown; no translation is generated or corrected.

        A living library

        Place this HTML beside the translation/ directory on a static site. The reader opens translation/juan-01.md first and can discover published Markdown files through the configured public GitHub repository. A reader-manifest.json file can supply the list instead. Local imports always work without a server.

        Your place stays yours

        Reading positions, bookmarks, and appearance preferences stay in this browser’s storage. Imported manuscripts are held in memory only, unless you explicitly save an offline reading copy. There is no analytics code or remote font dependency.
